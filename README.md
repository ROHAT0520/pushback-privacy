# Overflow — Gizlilik Politikası

Bu depo tek bir iş yapar: **Overflow** (`com.rohat.overflow`) adlı Android
oyununun gizlilik politikasını Google Play'in istediği herkese açık bir adreste
yayımlar.

Yayınlanan sayfa: `index.html` — tek dosya, dış bağımlılığı yok, TR + EN.

Kaynağı oyunun kendi deposundaki `docs/index.html`. Politika değişirse orada
değişir ve buraya kopyalanır (`Tools/publish-privacy.ps1`), böylece iki kopya
birbirinden ayrı düşmez.

GitHub Pages ayarı: Settings > Pages > Deploy from a branch > `main` / `/ (root)`
